# Showcase media

`specpi-showcase.mp4` is the 51-second, 1080p/60 fps revision 5 showcase. It uses staged demonstration content in the actual SpecPi Chat interface, plus an architectural delegation diagram. It is not a live model run. `showcase-poster.jpg` is a 1280 × 720 frame from the same edit.

The video is self-hosted, has no third-party player, and only plays when a visitor starts it. The HTML transcript provides the on-screen content and music credit.

## Homepage image

`specpi-chat-light.png` and `specpi-chat.png` are matching captures of the actual extension in VS Code’s Default Light Modern and Default Dark Modern themes. Both use the same isolated example workspace, conversation, viewport and panel widths. They were captured directly from VS Code without recoloring. The site selects the matching image for its theme. These are staged demonstrations, not live model runs.

## Improvement diagram

`improvement-workflow.png` and `improvement-workflow-mobile.png` are static diagrams generated for the homepage, arranged for wide and narrow screens. It shows observation, explicit human selection, bounded implementation, verification, and later review. Failed checks return to implementation; further changes require another human selection. The page includes an equivalent text description and adapts the same image for dark mode.
