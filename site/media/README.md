# Showcase media

`specpi-showcase.mp4` is the 51-second, 1080p/60 fps revision 5 showcase. It uses staged demonstration content in the actual SpecPi Chat interface, plus an architectural delegation diagram. It is not a live model run. `showcase-poster.jpg` is a 1280 × 720 frame from the same edit.

The video is self-hosted, has no third-party player, and only plays when a visitor starts it. The HTML transcript provides the on-screen content and music credit.

## Improvement diagram

The four `improvement-workflow*.svg` figures are generated by `python site/media/generate-workflow.py` using ReportLab, the same authoring tool as the research charts. They embed the site's IBM Plex Sans font and use explicit light and dark palettes. Desktop and mobile layouts have their own native dimensions; the page scales them uniformly without cropping or stretching.

The diagram shows observation, explicit human selection, modification of the Pi harness, verification, retirement, and later review. Failed checks return to modification; new work requires another human selection. The page and each SVG include equivalent text descriptions.
