# Showcase media

`specpi-showcase.mp4` is the 51-second, 1080p/60 fps revision 5 showcase. It uses staged demonstration content in the actual SpecPi Chat interface, plus an architectural delegation diagram. It is not a live model run. `showcase-poster.jpg` is a 1280 × 720 frame from the same edit.

The video is self-hosted, has no third-party player, and only plays when a visitor starts it. The HTML transcript provides the on-screen content and music credit.
