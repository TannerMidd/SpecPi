How it works

A control loop
with human approval.

Evidence recommends the work. One human choice starts it, and proof closes it.

01 / signal

Observe locally

Collection begins only after consent. Reusable gaps are sanitized, task-deduplicated, and stored locally. ZenPi never uploads them.

02 / decision

Choose one change

/harness-improvement opens one clean menu. Choosing an item starts its smallest-sufficient implementation workflow.

03 / outcome

Verify and finish

The harness runs the repository gate and closed validators, then retires only on success. The journal keeps the evidence, gates, changed files, and version; loop-health metrics show whether improvements stick.

Session command guard

Dangerous commands
stop at the door.

Every model-initiated command is analyzed before it runs. Confirmed catastrophe is denied outright, what the analysis cannot settle asks first, and ordinary work runs quietly.

Boundary: the guard provides defense in depth within its documented scope. Use least privilege, containers, or VMs for hostile code. Inspect or change the mode any time with /guard.

The goal

Let the environment learn from the work while people stay in control.

ZenPi makes friction legible, preserves each retirement's proof, and asks for the smallest intervention that can be proved and reversed.

Later friction links back to that journal, carries bounded context into human review, and updates local loop-health metrics without restarting work on its own.

Review the plan.
Then build.

Version v0.8.2 improves command-guard cleanup handling and keeps uncertain denials from locking later work.

Requires Node.js, npm, and Git. If Pi is missing, the confirmed install adds the reviewed pinned Pi package globally; ZenPi uninstall leaves it in place.

# clone a release you have reviewed
git clone --branch v0.8.2 --depth 1 https://github.com/TannerMidd/ZenPi.git
cd ZenPi

# Windows PowerShell / Command Prompt
.\zenpi.cmd plan
.\zenpi.cmd install
.\zenpi.cmd doctor

# Linux, macOS, or Git Bash
./zenpi plan
./zenpi install
