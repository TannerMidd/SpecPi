How scope works

The rest comes from eight pinned packages. Your Pi setup and choice of model stay yours.

Install SpecPi

npm install --global specpi@latest
specpi plan
specpi install
specpi doctor

Node.js 22.19+ · npm · Git · existing Pi on PATH
Tested with Pi 0.84.4. Review the plan, confirm, then restart Pi.

Updating or installing only the core?

Run specpi update after updating the npm package. Use --skip-package-install for scope and the improvement loop alone on a fresh install. Normal updates remove unchanged pi-lens entries added by SpecPi; independent or modified entries and downloaded files remain. The skip flag preserves the old base. Restart Pi and Chat connections to unload Lens.
