SpecPi adds two things of its own to the Pi coding agent: scope control and a harness improvement loop. Eight upstream packages handle the supporting tools.

Get started

Keep your Pi setup.

Install Pi and connect a provider first. SpecPi uses your existing provider and model settings.

Requires Node.js 22.19+, Git, npm, and Pi on PATH. The full base is tested with Pi 0.84.4. Pi Goal X supports Pi versions from 0.83.0 up to, but excluding, 0.85.0. 

npm install --global specpi@latest
specpi plan
specpi install
specpi doctor

Review the plan, confirm the install, then restart Pi. Use specpi install --skip-package-install if you only want scope and the improvement loop.

The core

Scope and a way to improve.

Declare the work with /scope

Use /scope set to name the files and directories a task should touch. Review changes with /scope status and add paths when the work needs them.

Interactive edits outside scope ask first. Shell commands and other tools are checked afterward, so scope monitors drift; it does not sandbox tools.

Improve from observed problems

Turn on local observations with /wishlist on. Review them with /wishlist, then choose a specific improvement through /harness-improvement in a SpecPi source checkout.

The loop records the agreed change and checks the result. Collection starts off, records stay local, and an observation never authorizes a change.

SpecPi Chat 0.7.1

Pi, beside your code.

Chat in VS Code with file and image attachments, conversation history, model controls, streamed tool output, and Git diffs.

The new base brings subagent activity and result cards, goal and background-task messages, usage reports, and permission dialogs into Chat.

Install the VS Code extension

  1. Download SpecPi Chat 0.7.1.
  2. In VS Code, run Extensions: Install from VSIX… and select the file.
  3. Open a trusted project, select SpecPi in the Activity Bar, and choose Connect Pi.

Requires VS Code 1.96+ and Pi on the workspace host. Install SpecPi separately. Provider sign-in and some package settings remain in terminal Pi.

Moving to 0.21.0

Start with the new base.

This release removes SpecPi's former custom tools, extra workflow commands, themes, and shell profiles. The eight packages replace the supporting tools; Chat remains available.

Updates back up managed resources, preserve unrelated settings, and keep modified retired files in local backups. Restart Pi, including Chat connections, to unload the old extensions. 

npm install --global specpi@latest
specpi plan
specpi update
specpi doctor
