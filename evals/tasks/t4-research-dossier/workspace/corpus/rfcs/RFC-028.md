# RFC-028 — Deprecate shard.rebalance.eager

Id: RFC-028
Status: superseded
Superseded-by: RFC-029

`shard.rebalance.eager` is deprecated. It was introduced for a migration that finished two releases ago
and no supported deployment sets it.

Configuration that still sets `shard.rebalance.eager` will warn at start-up and the key will be ignored.
