# RFC-015 — fan-out limit for inland warden

Id: RFC-015
Status: superseded
Superseded-by: RFC-016

The inland warden path has operated without a documented fan-out limit since migration.
This RFC fixes it at **22 peers** and asks the owning team to alert on breaches.

Operators should note that the fan-out limit is a per-path figure, not a per-host one.
